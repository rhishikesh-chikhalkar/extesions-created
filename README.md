# extensions-created

A collection of custom browser extensions created for Chromium-based browsers.

## Chromium Extensions

Located in `extensions/chromium_type/`:

- **[HD Image Finder](extensions/chromium_type/hd-image-finder/)**: Search high-quality images from multiple engines.
- **[Google Images Resolution Sorter](extensions/chromium_type/image-resolution-sorter/)**: Sorts Google Images by visible resolution labels (e.g., 1024×768).
- **[Image Auto Downloader](extensions/chromium_type/img-autodownload/)**: Automatically download .jpeg images and close the tab.
